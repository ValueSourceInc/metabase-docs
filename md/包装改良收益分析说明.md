# 包装改良收益分析说明（卡片 #1231）

> **三行结论**
>
> - **默认假设**：客户损坏和运输损坏降低 60%，质量问题不因包装改善（默认降 0）。
> - **判定标准**：保守口径节省 > 改良包装增量成本（默认 3 元/件），即判定为"值得"。
> - **当前结果**：115 个组合保守口径值得，10 个仅扩展口径值得，68 个不值得，4 个因基础资料缺失暂不能判断。

生效日期：2026-09-08（v3.1）。对应 Metabase 卡片：**包装改良节省与盈亏分析 (Packaging Savings & ROI) #1231**，
位于 Packaging 集合，建议与 Damaged Returns Cost Analysis 看板（dashboard 100）一起看。

## 一、这张表回答什么问题

退货里有一大批是"退回来的货已经损坏"——货卖不出去、还要付各种费用。
我们想改良包装把损坏降下来，但包装要花钱。这张表按 **每个 SKU × 每个尺寸** 算清楚三件事：

1. **能省多少钱**：假设包装改良后损坏减少（默认各类损坏降 60%），这个 SKU 在当前统计期间预计能省多少美金；
2. **最多能花多少钱**：每个 SKU 每件最多能花多少钱改包装，超过就亏；
3. **值不值得做**：直接给出结论——值得 / 仅扩展口径值得 / 不值得 / 数据不足。

## 三、怎么算的（大白话五步）

**第 1 步：数出每个 SKU 损坏了几件。**
退货记录里损坏分四类：客户损坏（2,264 件）、运输损坏（276 件）、质量问题（93 件）、其他损坏（1 件）。
默认假设前两类和"其他"能靠包装降 60%，**质量问题默认降 0%**——包装救不了产品本身的毛病。
每类降幅在卡片顶部的参数框里可以单独调。

**第 2 步：算损坏一件损失多少钱。**
= 该 SKU 的平均采购单价（货值）。
另有两笔附带费用：损坏退货的退款佣金和处理费（只作参考列，**不计入节省**——就算包装好了客户照样退货，这两笔费省不掉多少）；
销毁费按损坏量分摊（计入扩展口径）。

**第 3 步：算能省多少。**

- **保守口径**（判定"值得"用它）= 损坏货值 × 有效降幅。
  有效降幅就是四类损坏加权后的实际降幅，比如某 SKU 损坏 43 件里 1 件是质量问题，有效降幅就是 58.6% 而不是 60%。
- **扩展口径**（乐观上限）= (货值 + 销毁费分摊) × 有效降幅。

**第 4 步：算改良包装要花多少。**
默认每件多花 3 元人民币（参数可改）。总花费 = 卖出件数 × 每件增量成本（折美元）。

**第 5 步：净收益 = 省 − 花费，给出判定。**

- 净收益 > 0（按保守口径）→ **值得**
- 保守口径亏、扩展口径赚 → **仅扩展口径值得**
- 都亏 → **不值得**
- 缺尺寸或缺成本数据 → **数据不足**（不判值不值得，先补数据）

## 四、举例：DH-BT-BRAID-BR-K（King 尺寸编织毯）

| 数字               | 值                         | 白话                                                                                                         |
| ------------------ | -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 损坏退货           | 43 件（其中 1 件质量问题） | 15 个月里 43 件退回来是坏的                                                                                  |
| 卖出               | 289 件                     | 每 100 件卖出约 14.9 件损坏退回（损坏件数占销量）                                                            |
| 退货中损坏占比     | 87.8%                      | 退货记录中被标记为损坏的数量 ÷ 该 SKU 全部退货数量（43 ÷ 49）。注意：这不是"退货率"，也不是"损坏件数 ÷ 销量" |
| 平均采购单价       | $20.21                     | 一件货值 20 美金                                                                                             |
| 损坏货值           | $869                       | 43 × 20.21                                                                                                   |
| 有效降幅           | 58.6%                      | 60% 打折后（剔了 1 件质量问题）                                                                              |
| **保守口径节省**   | **$509**                   | 869 × 58.6%                                                                                                  |
| 包装花费           | 289 × $0.42 = $121         | 每件多花 3 元                                                                                                |
| **保守净收益**     | **$388**                   | 赚                                                                                                           |
| 保守成本上限       | $1.76/件（约 ¥12.6）       | 每件最多加这么多，现在只花 3 块，还能加                                                                      |
| 当前包装价         | $0.46/件（¥3.3）           | 现在的包装成本                                                                                               |
| **新包装总价上限** | **$2.22/件（约 ¥15.9）**   | 拿着这个数去问包装厂：报价不超过这个总价就能做                                                               |
| 判定               | **值得**                   |                                                                                                              |

**给采购的用法**：直接看「新包装总价上限」列，包装厂报价（注意是总价，不是增量）≤ 上限 → 可以签。

## 五、整体结论速览（默认参数：降 60%、增量成本 3 元/件）

- 197 个 SKU×尺寸组合：**值得 115、仅扩展口径值得 10、不值得 68、数据不足 4**
- 保守口径总节省 **$17,985**，净收益 **$1,942**；扩展口径总节省 $19,723，净收益 $3,680
- 头部集中在 **QS001 床垫系（King/Queen/Cal King）** 和 **DH-BT-BRAID King**——建议第一批做
- 薄毯 Throw（Leaves 系）天花板低（约 ¥2-3/件），3 元成本做不动
